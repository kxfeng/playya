# 小熊拼图书

给两三岁小朋友玩的拼图游戏，可以添加到桌面全屏玩，第一次打开后断网也能玩。

- 三个难度：简单 6 片、中等 9 片、难 16 片，12 张图，每张都可以选三种难度
- 碎片拖到任意格子附近都会吸附，全部放对后放烟花
- 页面不含文字，适合还不识字的小朋友

地址：https://kxfeng.github.io/playya/

## 添加到桌面

### iOS / iPadOS

1. 用 **Safari** 打开上面的地址
2. 点地址栏旁的分享按钮（方框加向上箭头）
3. 选「添加到主屏幕」，再点「添加」

### Android

1. 用 **Chrome** 打开上面的地址
2. 点右上角的 ⋮ 菜单
3. 选「添加到主屏幕」或「安装应用」，再点「安装」

之后从桌面图标打开就是全屏。
